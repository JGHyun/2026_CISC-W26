# 개요
연구 후속 검증을 위해 별도로 업로드한 사이버보안 통제체계 분석 관련 자료입니다.
<br />[표 1] ~ [표 5]에서 분석한 실 수치를 항목 단위로 비교분석하여 나타냈습니다.
<br />모든 분석 자료들은 CSV로 업로드 되어있습니다.
